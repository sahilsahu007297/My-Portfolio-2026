# Image sequence drop folder

Drop all 300 image frames directly in this folder (next to this README).

Use consistent zero-padded filenames so they sort correctly:

- `frame-0001.webp`
- `frame-0002.webp`
- `...`
- `frame-0300.webp`

WebP is recommended for fast loading. Do not place frames in a nested folder unless the component path is updated too.
